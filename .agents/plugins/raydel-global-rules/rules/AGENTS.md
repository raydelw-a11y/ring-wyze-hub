# Regla Global de Verificación de Despliegue (Render / Web Apps)

1. **Indicador de Actualización en Esquina (`Actualizado: [hora] - [mes/día/año]`)**:
   - Para verificar con certeza que los cambios se subieron y desplegaron en Render (`onrender.com`), cada vez que se haga un cambio en cualquiera de las aplicaciones, debe existir y actualizarse en una esquina con texto bien pequeño una etiqueta que diga:
     `Actualizado: [hora] - [mes/día/año]` en formato `MM/DD/YYYY` (ejemplo: `Actualizado: 12:41 AM - 10/21/2026`).
   - Debe ser visible tanto en la pantalla de contraseña (`Acceso Privado`) como en la pantalla principal de la aplicación.
   - En proyectos con Vite, además de actualizar el texto de respaldo en el componente, se inyecta `__BUILD_TIMESTAMP__` en `vite.config.js` / `vite.config.ts` con la hora y fecha actual (`America/New_York`, formato `en-US` `MM/DD/YYYY`).
   - Siempre ejecutar `npm run build` y hacer `git commit` + `git push` para que Render despliegue la versión actualizada.

2. **Pantalla de Contraseña (`Acceso Privado`) con Soporte para Tecla `Enter`**:
   - En todas las pantallas de contraseña, el formulario debe estar envuelto en `<form onSubmit={...}>` con `<button type="submit">` y manejador `onKeyDown` para `Enter`, garantizando que presionar la tecla `Enter` siempre funcione para acceder (y no únicamente hacer clic en el botón).
